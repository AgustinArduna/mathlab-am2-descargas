# MathLab AM II para Windows y Linux

Aplicación de estudio para preparar el final de Análisis Matemático II.

**[⬇ Descargar la última versión de MathLab](https://github.com/AgustinArduna/mathlab-am2-descargas/releases/latest)**

El mismo ZIP sirve para Windows y para Linux. En los dos casos necesitás Python 3; la guía de ejecución adjunta explica cómo instalarlo.

## Cómo abrir MathLab en Windows

1. En la página de descarga, buscá **Assets** y descargá el archivo `MathLab-AM-II-…zip`.
2. Descomprimí el ZIP.
3. Hacé doble clic en **Abrir MathLab.cmd**. Se abre `http://127.0.0.1:8000` en tu navegador. Dejá abierta la ventana del lanzador mientras estudiás.

## Cómo abrir MathLab en Linux

1. En la página de descarga, buscá **Assets**, descargá el archivo `MathLab-AM-II-…zip` y descomprimilo.
2. Abrí una terminal en la carpeta descomprimida y escribí `./abrir-mathlab.sh` (o `bash abrir-mathlab.sh`).
3. Se abre `http://127.0.0.1:8000` en tu navegador. Dejá abierta la terminal mientras estudiás. Para cerrar MathLab, apretá Ctrl+C en la terminal.

El lanzador de Linux todavía no se probó en una distribución real. Si no funciona, la sección «En Linux» de la guía explica cómo abrir MathLab a mano.

## Tu progreso

Si ya usabas MathLab, cerrá primero la versión anterior. Para conservar tu progreso, usá la misma dirección, navegador y perfil. El progreso no pasa solo de una computadora a otra: para llevarlo, exportalo e importalo desde «Progreso e historial».
